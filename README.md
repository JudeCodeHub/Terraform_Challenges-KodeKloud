# Terraform Challenges - KodeKloud

This repository contains my solutions to the **Terraform** challenges from [KodeKloud](https://kodekloud.com/).

## 📁 Repository Structure

The challenges are organized by their difficulty level and task number. 

- **Terraform-Level-01/**
  - **Task-01/**: AWS Key Pair Creation with Terraform
  - **Task-02/**: (Upcoming challenges...)

## 🚀 About

Each task folder contains:
- `main.tf` (and other Terraform configuration files as required by the challenge).
- A `README.md` file with a detailed description of the task requirements and instructions on how to execute it.

## 🛠️ Prerequisites

To test or run these configurations, you will need:
- [Terraform](https://developer.hashicorp.com/terraform/downloads) installed on your local machine.
- Appropriate Cloud Provider credentials configured (e.g., AWS, GCP, etc.) depending on the specific challenge requirements.
